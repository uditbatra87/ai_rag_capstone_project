Simple Example 01 Synchronous

Scope: 1 snippet × 4 strategies (sequential)  |  Model: gpt-4o-mini  |  API style: synchronous (blocking, one call at a time)
How this script works: each strategy is called one at a time in a for loop. The program blocks (pauses completely) while waiting for each API response before starting the next. Total time = sum of all 4 call durations.

Compare to simple_example_02.py, which uses AsyncOpenAI and await in the same loop structure — still sequential, but now async. simple_example_03.py then introduces asyncio.gather() to make all 4 calls truly concurrent.
